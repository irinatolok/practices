Ответы на вопросы:
1. Шифр Цезаря является моноалфавитным, поскольку каждая буква исходного текста заменяется одной и той же буквой зашифрованного алфавита на протяжении всего сообщения.
2. Шифр Цезаря относится к симметричным криптосистемам, поскольку для шифрования и расшифрования используется один и тот же секретный ключ - величина сдвига.
3.  Число разных преобразований зависит от длины алфавита. Для русского языка возможно 32 разных преобразования (преобразования ROT0 и ROT33 сохраняют исходный текст, а дальше начинаются уже повторения).
4.  Достоинства: простота реализации; небольшая вычислительная сложность; возможность ручного шифрования. Недостатки: маленькое пространство ключей; низкая криптографическая стойкость; уязвимость к подбору ключа и частотному анализу.
5.  Формула шифрования: C = (M + K) / mod N, формула расшифрования: M = (C - K) / mod N, где M - номер исходного символа, C - номер зашифрованного символа, K - ключ, N - количество букв алфавита.
### Задание №2. Шифр Виженера
Ключ: иринатолоконникова
Результат шифрования:
Йхрьптащэьбй ццяэтмижсц - ттщъу ьэяачйьке ррвцщчьщэьбц ццяэтмижсц, пгч цэээюьх щпжсшхатнн ус щщьвцмпьшииьеыодбз, епъьяышэуте щ мьсевыьщаай.
Ответы на вопросы:
1. Шифр Виженера является полиалфавитным, поскольку для шифрования используются несколько алфавитных замен. Сдвиг каждой буквы зависит от соответствующей буквы ключа.
2. Шифр Виженера является симметричным. Для шифрования и расшифрования используется один и тот же секретный ключ.
3. Если длина ключа составляет m символов, а алфавит содержит 33 буквы, количество возможных ключей равно (мощность равна): N = 33^m. Для ключа длиной 18 символов: N = 33^18 (как в моем случае).
4. Преимущества: по сравнению с шифром Цезаря обеспечивает более сложную замену символов; один и тот же символ исходного текста может шифроваться по-разному; относительно прост в реализации и использовании. Недостатки: при повторяющемся ключе возможно выявление закономерностей; при известной длине ключа шифр становится уязвимым для методов криптоанализа; не обеспечивает достаточной защиты по современным криптографическим стандартам.
5. Шифр Виженера является развитием шифра Цезаря. В шифре Цезаря для всех символов используется одинаковый сдвиг, а в шифре Виженера величина сдвига определяется символами ключевого слова.
6. Шифрование выполняется по формуле: C_i = (M_i + K_i) mod N, расшифрование: M_i = (C_i - K_i + N) mod N, где C_i - номер символа зашифрованного текста, M_i - номер символа открытого текста, K_i - номер символа ключа, N - количество символов в алфавите.
